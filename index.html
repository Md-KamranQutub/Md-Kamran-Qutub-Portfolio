Freelance · Full-stack e-commerce

Azowear

A fashion e-commerce platform with a microservices backend, Razorpay payments, a coupon engine and an admin dashboard.

  • API gateway plus auth, product, cart and order services, each with its own database, containerised with Docker Compose.
  • Phone-number OTP login with HttpOnly Redis sessions, customer and admin roles, and rate-limited login and OTP endpoints.
  • Razorpay with server-side signature checks, a webhook as backup, automatic refunds, and a job that expires unpaid orders and releases stock.
  • Atomic per-size stock reservation with rollback prevents overselling.
  • Server-side coupon engine with caps, minimum order and per-customer and total limits.
  • Admin dashboard with sales analytics, Cloudinary image management and CSV order export. Mobile-first storefront with a guest cart that merges at login.
